# SWYNEX Task 2 – Exploratory Data Analysis

## 📊 Project Overview

This project focuses on Exploratory Data Analysis (EDA) of a Titanic dataset using Microsoft Excel.

The objective is to analyze the dataset, identify patterns and trends, detect anomalies, and present the findings using statistical analysis and charts.

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Statistical Analysis
- Charts and Visualizations

## 📁 Project Contents

- `SWYNEX_Task_2_EDA.xlsx` – Complete EDA workbook
- `README.md` – Project documentation

## 📈 Analysis Performed

The analysis includes:

- Gender distribution
- Passenger class distribution
- Age distribution
- Fare distribution
- Statistical measures such as:
  - Mean
  - Median
  - Minimum
  - Maximum
  - Standard deviation
- Identification of unusual/high fare values
- Data visualization using charts

## 🔍 Key Insights

1. Male passengers represented approximately 64% of the dataset, while female passengers represented approximately 36%.
2. 3rd class passengers formed the largest group at approximately 52%.
3. The average and median passenger age were approximately 27 years.
4. The average fare was approximately 35.63, while the median fare was approximately 14.45.
5. The maximum fare was approximately 512.33, indicating an unusually high fare value compared with the median.
6. Passenger ages ranged from 0 to 76 years.

## 📌 Conclusion

The EDA provides an overview of passenger demographics, class distribution, age patterns, and fare distribution. The analysis also highlights unusual values that can be investigated further.
